# Asset & Software Licences — Temple Rush: Curse of the Lost Kingdom

## 1. Game code, art and audio (this repository)

* **Code** — released under the MIT licence (below).
* **Art** (`assets/raw/`, `assets/sprites/`, `assets/textures/`,
  `assets/ui/`) — original works generated by this project's own pipeline
  (`tools/process_assets.py`). No third-party art is included or derived
  from external packs. Reuse freely; attribution appreciated.
* **Audio** — synthesized in real time by the Web Audio API
  (`js/core/audio.js`). No audio files are distributed and no samples from
  Freesound or any other library are used.
* **Fonts** — only OS-provided system font stacks are referenced from CSS;
  no font files are bundled.

No asset in this game requires attribution beyond the three.js licence below.

## 4. Record of third-party asset sourcing

Per the project brief, the following sources were considered for assets:
Kenney.nl, Poly Haven, Quaternius, OpenGameArt.org, Sketchfab, ambientCG,
Freesound.org, Mixamo and Blender. **None were used**: the build environment
had network access only to GitHub and package registries, so no external
asset could be downloaded or licence-verified. As sanctioned by the brief,
all missing assets were created in-repo instead (procedural three.js
geometry, generated textures/sprites, synthesized audio). There are therefore
no third-party asset licences, attributions or modification records beyond
three.js itself.
